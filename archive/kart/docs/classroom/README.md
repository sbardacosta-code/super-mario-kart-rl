## Access

Reading this public GitHub index, reports, charts, and GIFs requires only a browser and internet access; no GitHub account or ROM is needed. Download release assets for checkpoints. Running the emulator requires a compatible local ROM and validated local save state, Python dependencies, and a Mac or another tested platform. Models alone do not include the game. No paid service is required.
